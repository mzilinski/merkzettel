# Tastenkürzel

Die Kürzel folgen Microsoft To Do, wo es eine Entsprechung gibt.

## Überall

| Kürzel | Aktion |
|---|---|
| <kbd>Meta</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> | Schnell erfassen aus jeder Anwendung (global; änderbar unter Systemeinstellungen → Tastatur → Kurzbefehle) |
| <kbd>Strg</kbd>+<kbd>N</kbd> | Feld für neue Aufgaben fokussieren |
| <kbd>Strg</kbd>+<kbd>L</kbd> | Neue Liste |
| <kbd>Strg</kbd>+<kbd>F</kbd> | Suchen |
| <kbd>Strg</kbd>+<kbd>R</kbd>, <kbd>F5</kbd> | Synchronisieren |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>Alt</kbd>+<kbd>↓</kbd> | Vorherige / nächste Liste |
| <kbd>Strg</kbd>+<kbd>Z</kbd> | Letztes Löschen, Verschieben oder gemeinsames Erledigen rückgängig machen |

## Aufgaben

| Kürzel | Aktion |
|---|---|
| <kbd>↓</kbd> im Feld für neue Aufgaben oder im Suchfeld | In die Aufgabenliste wechseln |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Vorherige / nächste Aufgabe |
| <kbd>Eingabe</kbd> | Details öffnen |
| <kbd>Strg</kbd>+<kbd>D</kbd> | Erledigen oder wieder öffnen |
| <kbd>Strg</kbd>+<kbd>T</kbd> | Zu Mein Tag hinzufügen oder daraus entfernen |
| <kbd>Entf</kbd> | Löschen (einige Sekunden lang rückgängig zu machen) |
| <kbd>Leertaste</kbd> | Zur Auswahl hinzufügen / aus der Auswahl entfernen |
| <kbd>Strg</kbd>+<kbd>A</kbd> | Alle auswählen |
| <kbd>Esc</kbd> | Auswahl aufheben, Details schließen |

## Maus

| Geste | Aktion |
|---|---|
| Klick | Details öffnen |
| <kbd>Strg</kbd>+Klick | Zur Auswahl hinzufügen |
| <kbd>Umschalt</kbd>+Klick | Bereich auswählen |
| Rechtsklick | Kontextmenü (Mein Tag, Stern, Fälligkeit, verschieben, löschen) |
| Dateien auf *Dateien* ziehen | Anhängen |
