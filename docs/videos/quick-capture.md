# Video script: Capture tasks from anywhere

Times are positions in the finished video. Actions use screen coordinates of
the 1920×1080 recording (window at 210,75, 1500×930); `en:`/`de:` limit an
action to one language. See [README](README.md) for the action reference.

Merkzettel runs hidden in the tray; KWrite stands in for "any application".

| Time | Action | English | Deutsch |
|---|---|---|---|
| 0:00 | `title` | A task comes to mind while you are writing an e-mail or reading a web page. | Dir fällt eine Aufgabe ein, während du eine Mail schreibst oder eine Webseite liest. |
| 0:06 | `en: type "Agenda for Thursday: budget review, two new hires, office move"; de: type "Agenda für Donnerstag: Budget, zwei Neueinstellungen, Büroumzug"` | Switching to a browser tab and finding the right list breaks your flow. With Merkzettel, it takes one shortcut. | Zu einem Browser-Tab wechseln und die richtige Liste suchen reißt dich raus. Mit Merkzettel genügt ein Tastenkürzel. |
| 0:16 | `key super+alt+n` | Press Meta, Alt and N in any application. Merkzettel comes to the front, with the cursor in the new task field. | Drück Meta, Alt und N, in jeder Anwendung. Merkzettel kommt nach vorn, der Cursor steht im Feld für neue Aufgaben. |
| 0:26 | `wait 0.5; en: type "Pay rent tomorrow"; de: type "Miete zahlen morgen"; poster` | Type the task. A date word at the end sets the due date: tomorrow, a weekday, or a date like the 25th of May. | Tipp die Aufgabe ein. Ein Datumswort am Ende setzt die Fälligkeit: morgen, ein Wochentag oder ein Datum wie der 25. Mai. |
| 0:37 | `key Return` | Press Enter. The date word disappears from the title, and the task is due tomorrow. | Drück Enter. Das Datumswort verschwindet aus dem Titel, und die Aufgabe ist morgen fällig. |
| 0:45 | `en: type "Call Anna fri"; de: type "Anna anrufen fr"; key Return` | Weekdays work the same way: this task is due on Friday. | Wochentage funktionieren genauso: Diese Aufgabe ist am Freitag fällig. |
| 0:53 | `wait 1; key alt+F4` | Close the window, and you are back where you left off. Merkzettel keeps running in the system tray. | Schließ das Fenster, und du bist wieder, wo du warst. Merkzettel läuft im Systemabschnitt weiter. |
| 1:02 | `en: type " Remember: rent is due tomorrow."; de: type " Nicht vergessen: Miete morgen."` | Let Merkzettel start with your session, and the shortcut is always ready. You can change it in the system settings. | Lass Merkzettel mit deiner Sitzung starten, dann ist das Tastenkürzel immer bereit. Ändern kannst du es in den Systemeinstellungen. |
| 1:13 | `end` | That is how you capture tasks from anywhere. | So erfasst du Aufgaben von überall. |
