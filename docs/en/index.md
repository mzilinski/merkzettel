# Merkzettel

**Microsoft To Do on the Plasma desktop.** Merkzettel is a native client for
Microsoft To Do, built with Qt and KDE's Kirigami. It talks to Microsoft Graph
directly — no web view, no browser tab — and keeps a local copy of your lists,
so it starts instantly and stays usable offline.

## Try it without an account

Every build contains a demo mode with sample lists and tasks. Choose
**Try the demo** on the sign-in page or start `merkzettel --demo`. You can add, complete
and edit tasks; nothing is sent to Microsoft and nothing is stored.

## At a glance

- Lists and tasks with due dates, reminders, recurrence, steps, notes,
  categories, links and file attachments
- Smart lists: My Day, All, Important, Planned and Completed
- Natural date input ("Pay rent tomorrow"), sorting, search, multi-selection,
  undo
- Global quick-add shortcut and a system tray icon with a due-today badge
- Personal Microsoft accounts and Microsoft 365 work or school accounts
- No telemetry: Merkzettel only talks to Microsoft
