# Keyboard shortcuts

The shortcuts follow Microsoft To Do where an equivalent exists.

## Everywhere

| Shortcut | Action |
|---|---|
| <kbd>Meta</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> | Quick add from any application (global; change it in System Settings → Shortcuts) |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | Focus the new-task field |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | New list |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Search |
| <kbd>Ctrl</kbd>+<kbd>R</kbd>, <kbd>F5</kbd> | Synchronise |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>Alt</kbd>+<kbd>↓</kbd> | Previous / next list |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo the last delete, move or bulk completion |

## Tasks

| Shortcut | Action |
|---|---|
| <kbd>↓</kbd> in the new-task or search field | Move into the task list |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Previous / next task |
| <kbd>Enter</kbd> | Open the details |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Complete or reopen |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | Add to or remove from My Day |
| <kbd>Delete</kbd> | Delete (can be undone for a few seconds) |
| <kbd>Space</kbd> | Add to / remove from the selection |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all |
| <kbd>Escape</kbd> | Clear the selection, close the details |

## Mouse

| Gesture | Action |
|---|---|
| Click | Open the details |
| <kbd>Ctrl</kbd>+click | Add to the selection |
| <kbd>Shift</kbd>+click | Select a range |
| Right-click | Context menu (My Day, star, due date, move, delete) |
| Drag files onto *Files* | Attach them |
